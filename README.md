# 👨‍💻 Sumeet Dhakad — Portfolio

> **Live Site:** [sumeet-source.github.io/portfolio](https://sumeet-source.github.io/portfolio/)

This is my personal developer portfolio — a modern, interactive, and responsive website that showcases my work as a **Backend Software Engineer** with 4+ years of experience.

---

## ✨ Features

- 🎨 **Dark Theme** with animated gradient background and floating orbs
- ⌨️ **Dynamic Typewriter Effect** — scrolls through my roles
- 📱 **Fully Responsive** — looks perfect on mobile, tablet, and desktop
- 🧠 **Live LeetCode Dashboard** — shows my daily problem-solving stats and heatmap
- 🖱️ **Smooth Scroll Animations** — powered by AOS (Animate on Scroll)
- 🔗 **Integrated Social Links** — GitHub, LinkedIn, LeetCode, Email

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **HTML5** | Structure |
| **CSS3** | Styling, animations, glassmorphism, gradients |
| **JavaScript** | Typewriter effect, smooth scrolling |
| **Font Awesome** | Icons |
| **AOS** | Scroll-triggered animations |
| **LeetCode Stats API** | Live heatmap and progress tracking |
